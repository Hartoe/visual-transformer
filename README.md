# Visual Transformer

This repository contains the code used for the Neural Factory educational game.

## Features
- Unity-based visual transformer project
- Ready to open and run in the Unity Editor
- Structured as a standard Unity project
- Easy to extend with additional scenes, assets, and scripts
- In the `Assets/Scripts/Utilities/ML` directory, you can find the scripts for implementing ML components and models

## Requirements
- Unity Editor: 2022.3.45f1 (see ProjectSettings/ProjectVersion.txt)

## Getting Started
1. Clone the repository
```sh
git clone https://github.com/Hartoe/visual-transformer.git
cd visual-transformer
```
2. Open the project
* Launch Unity Hub.
* Click Add (or Open in newer versions).
* Select the cloned repository folder.
* Open the project using Unity 2022.3.45f1.

If Unity prompts you to upgrade the project, it is recommended to use the exact editor version specified in ProjectSettings/ProjectVersion.txt to avoid compatibility issues.

## Project Structure
Assets/             Project assets, scripts, scenes, materials, and prefabs
Packages/           Unity package dependencies
ProjectSettings/    Unity project configuration
UserSettings/       Local editor preferences (optional)
Open the project in Unity.
Open the desired scene from the Assets folder.
Press the Play button in the Unity Editor.
